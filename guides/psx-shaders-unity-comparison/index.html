Which PSX shader belongs in your Unity project?

Compare CrowPSX, URP-PSX, Haunted PSX Render Pipeline, and PSX Retro using publisher documentation, pipeline requirements, and practical project needs.

Start with your render pipeline.

For a Unity project already using Built-in or URP, CrowPSX is worth considering when you want PSX geometry controls alongside terrain, foliage, PBR materials, and batch material tools. For a free Shader Graph starting point, investigate URP-PSX. Haunted PSX is an alternative when you can build around a dedicated render pipeline. PSX Retro is another option for Built-in projects.

These are different integration choices. Choose by project compatibility first, then by the visual controls and authoring workflow you actually need.

Choose for the game you are making.

CrowPSX: when the material workflow matters.

Consider CrowPSX when you want to stay in Built-in or URP and manage a broader set of world materials. Its package documentation covers Default, Lite, and PBR surfaces; four-layer vertex painting; wind-driven Nature variants; TerrainLayer materials; particles; depth-volume decals; and a procedural skybox.

Its Material Manager applies presets and compatible settings across materials. Stereo-stable snapping and separate VR controls are documented. These are useful evaluation criteria if your project has many materials or stereoscopic rendering requirements.

Tradeoffs: HDRP is excluded. URP decals and outlines need CrowPSX renderer features, and distortion needs Opaque Texture. Keep the installed package at Assets/CrowPSX. If your only requirement is full-screen pixelation or CRT presentation, evaluate a camera effect solution too. Read CrowPSX's compatibility and setup notes →

URP-PSX: when you want an open-source starting point.

Kodrin's project combines Shader Graph materials with URP renderer effects. Its README lists vertex snapping, color precision, texture pixelation, screen-space fog, dithering, and pixelation. The repository uses the MIT license.

Its documented compatibility is an older Unity/URP combination. Treat migration to a current project as work to verify, rather than assuming current-version support. The README also notes a PBR lighting issue. Read the original README →

Haunted PSX: when the pipeline is the foundation.

Haunted PSX uses its own render pipeline asset. This is a larger rendering choice than changing a material shader. Its installation guide walks through assigning that pipeline, and release 1.7.0 documents support through Unity 2022.2.

Investigate it when you can choose your project's rendering foundation around it. Verify a newer Unity version independently; the cited release notes do not establish Unity 6 support. Read the installation guide →

PSX Retro: another Built-in option.

PSX Retro's publisher describes low-resolution rendering, polygon jitter, and retro image effects. The store compatibility table marks Built-in compatible and URP/HDRP incompatible for its listed Unity versions. For a Built-in project, review its demo and current feature list against your desired presentation. See the publisher's listing →

Check the real cost of integration.

URP-PSX is MIT-licensed; its purchase cost and the time needed to adapt it are separate questions. CrowPSX was listed at US$24.99 and PSX Retro at US$9.99 when checked. Store prices, regional pricing, taxes, licenses, and promotions can change; the live checkout is authoritative. For Haunted PSX, check its repository license and installation requirements.

Before adopting any tool, reproduce your intended look in a small representative scene. Include the actual target hardware, your lighting setup, transparency, vegetation, and camera motion. No comparative frame-rate claims are made here.
