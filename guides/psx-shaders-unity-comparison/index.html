01 — The short answer

Start with your render pipeline.

These are different integration choices. Choose by project compatibility first, then by the visual controls and authoring workflow you actually need.

IF YOU'RE ON BUILT-IN OR URP AND WANT…

03 — Which one fits?

Choose for the game
you're making.

Built-in + URP · this site's product

CrowPSX: when the material workflow matters

Good fit

  • Stay in Built-in or URP and manage a broader set of world materials
  • Default, Lite, and PBR surfaces; four-layer vertex painting; wind-driven Nature variants; TerrainLayer materials
  • Particles, depth-volume decals, and a procedural skybox
  • Material Manager presets; stereo-stable snapping and separate VR controls

Watch for

  • HDRP is excluded
  • URP decals and outlines need CrowPSX renderer features; distortion needs Opaque Texture
  • Keep the installed package at Assets/CrowPSX
  • If your only requirement is full-screen pixelation or CRT presentation, evaluate a camera effect solution too
Read compatibility and setup notes →

URP / Shader Graph · by Kodrin

URP-PSX: an open-source starting point

Good fit

  • Shader Graph materials combined with URP renderer effects
  • README lists vertex snapping, color precision, texture pixelation, screen-space fog, dithering, and pixelation
  • MIT license

Watch for

  • Documented compatibility is an older Unity/URP combination; treat migration as work to verify
  • The README notes a PBR lighting issue
Read the original README ↗

Dedicated pipeline

Haunted PSX: when the pipeline is the foundation

Good fit

  • You can choose your project's rendering foundation around it
  • Uses its own render pipeline asset; the installation guide walks through assigning it

Watch for

  • A larger rendering choice than changing a material shader
  • Release 1.7.0 documents support through Unity 2022.2; the cited notes do not establish Unity 6 support
Read the installation guide ↗

Built-in · by AK STUDIO ART

PSX Retro: another Built-in option

Good fit

  • Publisher describes low-resolution rendering, polygon jitter, and retro image effects
  • Built-in projects evaluating a packaged effect toolkit

Watch for

  • Store table marks URP and HDRP incompatible for its listed Unity versions
  • Review its demo and current feature list against your desired presentation
