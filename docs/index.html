    Build your first retro material#

    CrowPSX is a shader and material-authoring suite for Unity's Built-in Render Pipeline and Universal Render Pipeline. This manual covers installation, shader controls, scene setup, and troubleshooting for version 1.1.0.

    New to CrowPSX? Start here:

    1. Install and validate. Keep CrowPSX at Assets/CrowPSX and run the installation validator. Installation →
    2. Make one material. Choose Default, Lite, or PBR, assign a texture, then tune lighting and retro geometry. Getting started →
    3. Build out the scene. Add foliage, terrain, particles, decals, and a procedural sky using the matching shader families. Shader reference →

    What is included?#

    Surface, vertex-painting, and Nature shaders each offer Default, Lite, and PBR variants. The suite also includes Terrain PBR, Standard and Grab Distortion particles, depth-volume decals, and a procedural skybox.

    The inspector shows the controls available for your selected shader. Use the family references to compare variants and choose the features you need.

    Before you begin#

    Use Unity 2022.3 LTS or newer with Built-in or URP. HDRP shaders are not included. Polybrush and Bakery are optional. For exact version and renderer details, read pipeline compatibility.

    Explore the included demo to see how materials, meshes, lighting, and the camera work together, then use these guides to build your own look.
