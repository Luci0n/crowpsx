    Built-in and URP#

    Every lit CrowPSX shader ships both a Universal and a Built-in SubShader in the same asset, and Unity picks the one matching the active pipeline. A material keeps working when a project switches pipelines, nothing to install, copy, reassign, or upgrade, and no separate URP shader menu. Detection is automatic.

    Most of the package behaves identically in both. The exceptions:

    Feature Built-in Universal
    Particles/Grab Distortion Refracts through GrabPass Needs Opaque Texture on the URP Asset
    Decals/Depth Volume Reads scene depth directly Needs the CrowPSX Depth Volume renderer feature
    Terrain/PBR Built-in Terrain add-pass and basemap shaders URP's terrain contract
    Additional realtime lights One ForwardAdd pass per light Looped inside the single forward pass
    Bakery alpha-meta Separate pass, hidden from Unity's lightmapper Folded into the single Meta pass

    Under URP, depth-volume decals need the CrowPSX Depth Volume renderer feature on the active Universal Renderer, or they drift as the camera moves. Select a Depth Volume material and use the inspector's Add To Renderer action; the installation validator also reports it. Builds automatically strip the passes belonging to the pipeline you are not using, add CROWPSX_DISABLE_VARIANT_STRIPPING to turn that off.

    Optional mesh-surface outlines are controlled directly from each material, including screen-fixed/world-space width, distance fade, a UV mask, sampled base-color matching, and UV4-baked smooth outline normals for closing hard-edge gaps without changing surface shading. Built-in needs no setup. URP renders only the passes its renderer asks for, so the outline needs a draw request: add CrowPSX Outline Feature to the active Universal Renderers, or put a CrowPSX Outline Support component on a camera to cover one scene without touching the project, which is how a scene can ship with working outlines.

    Version and platform checks#

    The package documentation lists testing on Unity 2022.3, 6.0, 6.3, and 6.6. HDRP is not included. Use a Shader Model 3.5-capable target for the main surface, particle, and decal shaders.

    Compatibility statements describe the creator's tested setup. Validate your exact Unity version, URP version, renderer, graphics API, and target hardware with a representative scene.

    After changing pipelines#

    Wait for compilation and run Tools > CrowPSX > Validate Installation. Check the active Universal Renderer when using decals or outlines, and enable Opaque Texture when using URP Grab Distortion.

    If generated pipeline detection falls out of step, use Tools > CrowPSX > Regenerate Pipeline Defines. See Troubleshooting for include errors and camera-depth issues.
