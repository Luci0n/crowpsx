    Installation

    Requirements, package import, installation checks, and the included demo.

    PACKAGE VERSION 1.1.0
    On this pageRequirementsImport the packageValidate the installationOpen the included demoNext step

    Requirements#

    • Unity 2022.3 LTS or newer, tested on 2022.3, 6.0, 6.3 and 6.6
    • Built-in Render Pipeline or Universal Render Pipeline (Forward, Forward+ and, on Unity 6.6, Deferred+), HDRP shaders are not included
    • Shader Model 3.5-capable target for the main surface, particle, and decal shaders
    • Install through the Asset Store and keep the folder at Assets/CrowPSX
    • Polybrush and Bakery are both optional
    • The demo scene uses Unity UI, and runs under the Input Manager, the Input System, or both

    Import the package#

    1. Import the complete Assets/CrowPSX folder and leave it at that path.
    2. Run Tools > CrowPSX > Validate Installation.
    3. Create a material and choose a shader from the CrowPSX menu.

    See Getting Started for the first material, and Demo Scene for the playable scene at Assets/CrowPSX/Demo.unity.

    Validate the installation#

    Run Tools > CrowPSX > Validate Installation after import and after changing render pipelines. The validator checks shader discovery, required package contents, shader properties, assembly placement, and relevant URP renderer setup. It reports issues without changing project settings or material assets.

    Wait for Unity to finish compiling before checking shaders and inspector controls. If Unity reports an error, start with the first relevant Console message and use the troubleshooting guide.

    Open the included demo#

    Open Assets/CrowPSX/Demo.unity. The demo works with the Input Manager, Input System, or both. Find its controls and sample scripts in Demo scene.

    Next step#

    Create a material using CrowPSX/Surface/Lite or CrowPSX/Surface/Default, assign a Base Texture, and apply it to a mesh. Continue with Getting started for lighting, geometry, and rendering controls.
