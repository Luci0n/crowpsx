    1.1.0: Unity 6 Compatibility#

    Recent Unity 6 releases changed several URP and editor APIs. This update keeps CrowPSX working on every version from Unity 2022.3 LTS to Unity 6.6. Existing materials need no changes.

    Compatibility#

    • URP Forward+ on Unity 6.1 and newer. Point and spot lights render under Forward+, the default rendering path in new Unity 6 projects. These versions renamed the Forward+ shader keyword (_FORWARD_PLUS to _CLUSTER_LIGHT_LOOP); CrowPSX supports both, and builds only include the one your URP version uses.
    • URP Deferred+ (Unity 6.6). Supported as a rendering path, including Vertex-mode lighting.
    • Terrain on Unity 6.6. URP terrain materials render correctly after URP's terrain shader changes.
    • Clean import on Unity 6.6. No "Script Updating Consent" dialog and no deprecation warnings in the Console.
    • Input System projects. The demo scene runs in projects set to the Input System only, the default for new Unity 6 projects, with no Player Settings changes.

    Changed#

    • Vertex Hybrid under URP now matches Built-in: each light's shading, specular included, is calculated per vertex, while its falloff (and, on URP Forward, its shadow) is applied per pixel. The four most important point and spot lights get this treatment; any others are lit fully per vertex.
    • Documentation. The Shader Reference now explains the three lighting modes, light limits, and which lights cast shadows in each pipeline. The demo scene documentation reflects the new input support.

    1.0.0: Initial Public Release#

    The first public release of CrowPSX for Unity's Built-in Render Pipeline and Universal Render Pipeline.

    Render pipelines#

    • Every lit shader carries both a Universal and a Built-in SubShader in the same shader asset, so materials survive a pipeline switch without being copied, reassigned, or upgraded.
    • Automatic URP detection through a generated shader define, with Tools > CrowPSX > Regenerate Pipeline Defines as a manual fallback.
    • Build-time stripping of the forward passes belonging to the pipeline a build is not using, disabled by the CROWPSX_DISABLE_VARIANT_STRIPPING scripting define.
    • CrowPSX Depth Volume renderer feature for URP, with detection and one-click installation from the material inspector and the installation validator.
    • CrowPSX Outline renderer feature for URP, with detection and one-click installation from the material inspector, since URP's object draw does not execute the additional outline pass on its own.
    • CrowPSX Outline Support component as the per-scene alternative to that feature, requesting the same pass per camera so a shipped scene draws outlines without the project being set up. Built-in needs neither.

    Shader suite#

    • Surface Default, Lite, and PBR shaders.
    • Four-layer Vertex Painting Default, Lite, and PBR shaders using Base, Red, Green, and Blue vertex-color layers.
    • Nature Default, Lite, and PBR shaders with animated foliage deformation.
    • Terrain PBR shader with Built-in additional-pass, basemap, and basemap-generation support, and URP terrain-contract support.
    • Standard and Grab Distortion particle shaders.
    • Depth Volume decal shader.
    • HDR Procedural Skybox shader.

    Surface rendering and retro controls#

    • Pixel or vertex realtime lighting with direct, indirect, ambient, minimum-light, and stepped-lighting controls.
    • Final-color grading and posterization.
    • Screen-space vertex snapping, affine texture warping, and configurable pixel-snap templates.
    • Opaque, Cutout, and Transparent rendering with alpha maps, bake-transparency maps, clipping, dithering, depth, culling, render queue, and GPU instancing controls.
    • Stereo-stable geometry snapping for Multi-Pass, Single Pass Instanced, and Android Multiview VR.
    • Visible VR / Stereo Comfort controls with Off, Comfort, Balanced, and Full profiles plus independent VR Snap and VR Affine strengths.
    • Optional inverted-hull outlines on all six mesh-surface shaders, with screen-fixed or world-space width, distance fade, texture masking, and sampled base-color matching. Disabled materials submit no outline draw.

    PBR materials#

    • Separate Maps and Packed Map workflows for Surface PBR and Nature PBR, with an independent workflow for every painted PBR layer.
    • Smoothness or Roughness surface-response workflows, including independent selection per painted layer.
    • Normal, Metallic, Ambient Occlusion, Height, surface-response, detail, direct-specular, and reflection-probe controls.
    • Packed PBR channel layout: R Metallic, G Ambient Occlusion, B Height, and A Smoothness or Roughness. Normal maps remain separate.
    • Height-based parallax occlusion mapping with 1–64 integer steps, grazing-angle stabilization, Parallax Height up to 1, and Height Floor controls.
    • Signed normal strength from -4 to 4, supporting inverted tangent-space relief.
    • Specular Strength and Reflection Strength ranges from 0–4.
    • Linked core PBR UV transforms or independent transforms for individual maps.
    • Runtime-efficient packed sampling, disabled-feature early-outs, and zero-weight sampling skips for painted layers.
    • A themed packed-map creation card that previews channels, requests confirmation, creates a linear PNG beside the surface-color texture when possible, assigns it, and switches the relevant material or painted layer to Packed Map without removing separate-map assignments.
    • Automatic Detail Packed PBR creation when enabled detail maps are packed on Surface or Nature PBR materials.
    • Inspector channel guides and performance guidance for expensive painted Separate Maps configurations.

    Grunge and emission#

    • Grunge projection, masking, color, opacity, and blend controls on supported shaders.
    • Normal grunge compositing for placing the masked grunge result over the underlying surface.
    • Grunge influence across supported PBR responses, including signed height embossing and carving.
    • Texture-driven emission with masks, UV controls, source shaping, animation, HDR color, and strength controls.
    • Unclamped Unity Meta emission output for Progressive Lightmapper baking and Bakery-compatible alpha-meta support.

    Vertex painting#

    • Four independently authored Base, Red, Green, and Blue material layers.
    • Independent Albedo, tint, UVs, PBR map workflow, surface-response workflow, linked UV state, maps, strengths, Parallax Height, and Height Floor per PBR layer.
    • Shared integer Parallax Steps across the four painted layers.
    • Normalized layer blending across Albedo, Normal, Metallic, Ambient Occlusion, Height, surface response, and texture alpha.
    • Recommended Polybrush Texture Paint metadata and a setup helper under Tools > CrowPSX > Polybrush.

    Nature and terrain#

    • Anchored Nature wind with wind direction, sway, gusts, leaf flutter, plant variation, flex shaping, mask falloff, and presets.
    • Local Height, Vertex Alpha, UV2 Y, and texture-mask anchoring sources, with channel selection and inversion for the mask texture.
    • Matching realtime deformation in Forward and ShadowCaster passes; baked output uses the static rest pose.
    • TerrainLayer Albedo, Normal, Metallic, Smoothness, holes, additional-layer rendering, distant basemaps, lighting, color, and pixel-snapping support.

    Particles and decals#

    • Particle flipbooks, masks, secondary textures, packed VFX maps, custom particle streams, soft-particle fading, dissolve, distortion, intersection effects, distance/camera fades, and presets.
    • Grab Distortion framebuffer refraction in Multi-Pass with a stereo-safe heat-ripple fallback in Single Pass Instanced and Multiview.
    • Depth-volume projection with Normal, Premultiplied, additive-family, and Multiply blending suitable for graffiti, stickers, lighting, and stylized volume effects.
    • Independent Unlit Strength and unclamped HDR Emission Color/Strength for depth-volume decals.
    • Stencil presets for Block Decals, Respect Blockers, Receiver, and Test Receivers.

    Procedural skybox#

    • HDR zenith, horizon, and ground gradients with exposure, color grading, and HDR-safe posterization.
    • Multiple textured celestial bodies with independent placement, shape, tint, glow, and mask controls.
    • Analytic moon phases with eight presets, phase cycle, terminator rotation and softness, earthshine, phase-aware glow, and full-disc star occlusion.
    • Texture Alpha, Brightness (Luminance), and Alpha × Brightness celestial mask modes.
    • Spherical star fields with configurable population, appearance, distribution, and height fading.
    • One or two cloud layers with masks, self-shading, and lighting from the strongest enabled above-horizon Sun or Moon.
    • Transparent surroundings/skyline rendering.
    • Global orientation, automatic rotation, frame-stepped movement, and independent motion for celestial bodies, stars, clouds, and surroundings.
    • Environment lighting controls that hold Unity's ambient source on Skybox, optionally filter or tint the generated ambient probe, and apply to the active scene automatically or on demand.
    • Sky-specific diagnostics for invisible settings, costly combinations, mask configuration, cloud lighting, and motion.

    Material authoring tools#

    • Custom themed material inspectors with search, modified-only filtering, foldable groups, reset controls, contextual descriptions, and guarded high-cost ranges.
    • Material diagnostics with severity grouping and actionable repair suggestions.
    • Built-in and user-defined material presets.
    • Material Manager for collecting, filtering, converting, copying, resetting, and batch-editing compatible materials.
    • Batch rendering, lighting, preset, and VR Profile operations.
    • Outline Normals baking, from the material inspector or Tools > CrowPSX, which writes position-welded smooth normals into UV4 so an inverted hull stays closed across hard edges, leaving surface shading untouched and the original mesh restorable.
    • Installation validator and shader/material schema migration support.

    Compatibility and package content#

    • Unity 2022.3 LTS or newer.
    • Built-in Render Pipeline support with Forward lighting, shadows, fog, lightmaps, reflection probes, Light Probe Proxy Volumes, and required Unity variants.
    • Universal Render Pipeline support from the same shader assets, including its forward light loop, terrain contract, Single Pass Instanced and Multiview XR modes, and opaque-texture refraction.
    • Baked Indirect, Shadowmask, and Subtractive mixed lighting on Surface, Vertex Painting, Nature, and Terrain materials in both render pipelines.
    • Progressive Lightmapper HDR emission and transparency extraction through dedicated lightweight Meta passes.
    • Bakery alpha-meta compatibility on supported surface shaders in both render pipelines.
    • A self-contained playable demonstration scene with namespaced first-person sample scripts, referencing no content outside the package.
    • Third-party notices, setup documentation, shader reference, workflow guides, and troubleshooting documentation.

    Before you start#

    Run Tools > CrowPSX > Validate Installation after importing the package, and back up your project before a bulk material operation.
