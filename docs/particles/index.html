    SHADER REFERENCE

    Particles

    Standard particle effects, scene distortion, and stereo behavior.

    PACKAGE VERSION 1.1.0
    On this pageCrowPSX/Particles/StandardCrowPSX/Particles/Grab Distortion

    CrowPSX/Particles/Standard#

    A ParticleSystem-oriented shader with alpha, premultiplied, additive, soft-additive, multiply, hybrid-add, cutout, and opaque modes. It supports ParticleSystem vertex color, lit/self-lit response, flipbooks and manual atlases, texture arrays, secondary and mask maps, packed VFX input, color ramps, custom streams, soft particles, depth/intersection/distance fades, UV distortion, dissolve, alpha shaping, dithering, and built-in particle presets.

    CrowPSX/Particles/Grab Distortion#

    Includes the Standard particle feature set and a GrabPass scene-distortion path for heat haze, shockwaves, and refractive VFX. Multi-Pass and legacy double-wide stereo use true scene refraction. Single Pass Instanced and Multiview use a stereo-safe particle-surface ripple fallback to prevent cross-eye sampling. GrabPass can be expensive when many materials or draw calls use it.
