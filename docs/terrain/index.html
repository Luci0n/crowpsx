    SHADER REFERENCE

    Terrain

    TerrainLayer materials, pipeline support, and terrain-specific controls.

    PACKAGE VERSION 1.1.0
    On this pageCrowPSX/Terrain/PBR

    Select the Terrain object, open Terrain Settings, set Material to Custom, then assign a material using CrowPSX/Terrain/PBR.

    CrowPSX reads the Terrain's existing TerrainLayers, including their albedo, normal, metallic, smoothness, and holes data. In the Built-in Render Pipeline, Unity automatically uses the bundled supporting terrain passes for more than four layers and for the distant basemap; keep those hidden shaders in the original CrowPSX/Shaders/Terrain folder. Under the Universal Render Pipeline the same shader follows URP's own terrain contract and the hidden Built-in helpers are unused.

    CrowPSX/Terrain/PBR#

    A Terrain material that uses Unity TerrainLayers for albedo, normal, metallic, smoothness, and holes data. It supports Unity's standard terrain splatmap workflow, including the far-distance basemap and additional-layer rendering.

    Assign a CrowPSX/Terrain/PBR material through the Terrain object's Terrain Settings > Material > Custom field. In the Built-in Render Pipeline the following supporting shaders are selected automatically by Unity and should not be assigned directly:

    • Hidden/CrowPSX/Terrain/AddPass for TerrainLayers beyond the first four
    • Hidden/CrowPSX/Terrain/Base for the far-distance basemap
    • Hidden/CrowPSX/Terrain/BaseGen for basemap generation

    Under the Universal Render Pipeline the same shader follows URP's terrain contract, including its splat and basemap handling, so those hidden Built-in helpers are unused there.

    Terrain materials expose CrowPSX tint, pre/post-lighting color adjustment, pixel or vertex lighting, stepped lighting, final posterization, screen-space pixel snapping, and rendering controls. TerrainLayers remain the source of layer texture data; edit them through Unity's Terrain tools. Realtime terrain shadow casting remains unsnapped. Terrain materials do not use affine texture warping, so a VR profile applies only its snap setting to them.
